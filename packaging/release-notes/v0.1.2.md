SpotiVista 0.1.2 brings full startup compatibility for Windows 7 SP1 and Windows Vista SP2, introduces the new Aero glass play button icon, and routes first-time listeners straight to the built-in native player.

## New

- **Aero glass play button logo.** The application now features an authentic Aero-styled glass play button across the application executable, window title, system tray, and in-app interface.
- **Fork attribution and releases link.** Settings now attributes upstream Spotifast to Carmine Paolino, credits the Windows Vista and 7 fork by @stachustyrta, and provides a direct shortcut to check SpotiVista releases on GitHub.

## Fixed

- **Launches cleanly on Windows 7 SP1.** Resolved entry point loader failures by introducing dynamic compatibility shims for `ProcessPrng` (with `RtlGenRandom` fallback), `PowerRegisterSuspendResumeNotification`, `ActivateAudioInterfaceAsync`, and `SetProcessInformation`.
- **First-run setup no longer offers or fails on Spotify Soloist.** Bypassed the Soloist onboarding wizard and installer, ensuring new installs launch immediately into SpotiVista's native built-in player.
- **Decoupled from upstream Spotifast auto-updates.** Upstream update prompts and auto-download checks have been disabled so SpotiVista installations are not replaced by upstream binaries.
- **Rebranded visible strings.** Window titles, tray notifications, toasts, and settings strings across all locales now identify the application as SpotiVista.
