SpotiVista 0.1.3 (build 0.1.3.2) improves vintage Windows compatibility, eliminating startup entry point errors and laying groundwork for Windows Vista SP2 support planned in the future.

## Changes

- **Fixed Windows Vista startup entry point error (K32GetPerformanceInfo).** Dynamically bridges kernel32 calls to psapi.dll on older systems, resolving startup entry point failures.
- **Audited and shimmed Windows 7+ only APIs.** Added dynamic link-time shims for SetThreadErrorMode, PowerCreateRequest, SetWindowDisplayAffinity, ChangeWindowMessageFilterEx, Windows Touch APIs, and Shell_NotifyIconGetRect.
- **Windows Vista support status.** Windows 7 SP1 is the currently supported platform. Full Windows Vista SP2 support is planned in the future as AFD socket polling compatibility is completed.
