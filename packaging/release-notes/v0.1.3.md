SpotiVista 0.1.3 (build 0.1.3.2) brings full Windows Vista SP2 compatibility, eliminating startup entry point errors and resolving access denied errors during Spotify login and socket initialization.

## Fixed

- **Fixed Windows Vista startup entry point error (K32GetPerformanceInfo).** Dynamically bridges kernel32 calls to psapi.dll on Windows Vista, resolving startup entry point failures.
- **Audited and shimmed Windows 7+ only APIs.** Added dynamic link-time shims for SetThreadErrorMode, PowerCreateRequest, SetWindowDisplayAffinity, ChangeWindowMessageFilterEx, Windows Touch APIs, and Shell_NotifyIconGetRect to ensure clean execution on Windows Vista SP2.
- **Fixed Access is denied (os error 5) during login.** Resolved SetFileCompletionNotificationModes failure on Windows Vista AFD socket handles, allowing Tokio and mio loopback redirect listeners to initialize and complete browser authorization.
