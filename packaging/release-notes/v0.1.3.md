SpotiVista 0.1.3 (build 0.1.3.2) brings full Windows Vista SP2 and Windows 7 SP1 compatibility, eliminating startup entry point errors, bundling modern Mozilla root certificates for Spotify CDN streaming, and shimming Windows 7 directory and socket APIs.

## Fixed

- **Fixed Windows Vista startup entry point error (K32GetPerformanceInfo).** Dynamically bridges kernel32 calls to psapi.dll on Windows Vista, resolving startup entry point failures.
- **Audited and shimmed Windows 7+ only APIs.** Added dynamic shims for SetThreadErrorMode, PowerCreateRequest, SetWindowDisplayAffinity, ChangeWindowMessageFilterEx, Windows Touch APIs, and Shell_NotifyIconGetRect.
- **Fixed Spotify CDN playback errors (InvalidCertificate UnknownIssuer).** Switched to webpki-roots bundle to provide modern root CA certificates directly within the binary, resolving playback failure on Windows Vista where system root CAs are outdated.
- **Fixed directory scan failure on Windows Vista (os error 87).** Added FindFirstFileExW fallback that automatically coerces FindExInfoBasic (Win7+) to FindExInfoStandard (Vista) and strips FIND_FIRST_EX_LARGE_FETCH on Windows Vista.
- **Resolved AFD completion notification and socket polling on Vista.** Patched IAT at process initialization to allow mio and Tokio socket polling to succeed on Windows Vista.
